# 🧠 SKILL: LearningIntelligence (CAP Vision Learning System)

**Role**: AI Learning & Transformation Architect (Kruden Style)
**Objective**: Transform static articles into an interactive Learning Ecosystem using a Multi-Agent Architecture.

---

## 🤖 1. MULTI-AGENT ARCHITECTURE

### 🧩 Agent 1: Insight Curator (The Matchmaker)
- **Primary Goal**: Precision tagging and learner-persona alignment.
- **Skills**: 
  - **Content Tagging**: Assign tags (Leadership, Facilitation, HR Strategy).
  - **Persona Matching**: Identify target (HR, Manager, Trainer).
  - **Knowledge Gaps**: Detect if content is too easy or too advanced for the user's current challenge.

### 🧩 Agent 2: Transformative Learning Coach (The Reflector)
- **Primary Goal**: Drive "Deep Learning" via reflection.
- **Skills**:
  - **Reflection Questions**: Generate 3-step questions (What? So What? Now What?).
  - **Mindset Reframing**: Challenge existing beliefs based on article insights.
  - **Learning Summary**: Condense the "essence" of transformation.

### 🧩 Agent 3: Facilitation Designer (The Process Architect)
- **Primary Goal**: Article → Practical Workshop.
- **Role Identity**: Facilitator = Designer of Process, not just a teacher.
- **Skills**:
  - **Workshop Agenda**: Create 60-120 min training flows.
  - **Activity Design**: Icebreakers, Group Work, "Aha!" moments.
  - **Tool Recommendation**: Suggest specific CAP Vision Cards or Canvases.

### 🧩 Agent 4: Knowledge-to-Action (The Performance Coach)
- **Primary Goal**: Insight → Action Plan/Results.
- **Skills**:
  - **Action Planning**: Creating 7-30 day roadmaps.
  - **OKR/KPI Alignment**: Connecting article topics to business results.
  - **Habit Design**: Implementing "Micro-habits" from the content.

### 🧩 Agent 5: Content Repurposing (The Multiplier)
- **Primary Goal**: Format Transformation for maximum reach.
- **Skills**:
  - **Micro-learning**: Extract 1-min key takeaways.
  - **Social Content**: Write punchy LinkedIn/Facebook posts.
  - **Visual Aids**: Draft slide outlines or infographic data points.

## 🧱 2. UI/UX CORE PILLARS

| Component | Functionality |
|-----------|---------------|
| **Smart Search** | Search + Recommend + Coach. Placeholder: "คุณอยากพัฒนาทักษะอะไรวันนี้?" |
| **Learning Path Filter** | 4 Pillars: Leadership, Facilitation, Transformation, HR Strategy. |
| **Reflection Panel** | Bottom of article. Interactive input for Insight, Thinking Shift, and Next Day Action. |
| **AI Coach Sidebar** | Contextual Chat: "Summarize for the team" or "Design workshop from this". |
| **Action Box** | Links to specific Canvases and Workshop Templates. |

---

## 🔄 3. TRANSFORMATIVE LEARNING LOOP
1. **Experience**: Read/Watch the content.
2. **Reflection**: Use the *Reflection Panel* to rethink.
3. **Insight**: AI summarizes the shift in perspective.
4. **Action**: Generate an *Action Plan* or *Workshop Agenda*.
5. **Transformation**: Track application and feedback (Future Phase).

---

## 🧭 4. PROMPT LOGIC FOR ANTIGRAVITY
When analyzing an article, always output in this structure:
1. **Curator Metadata**: (Tags, Persona, Difficulty Level).
2. **Coaching Prompts**: (3 Reflection Questions).
3. **Workshop Seed**: (One 15-min group activity based on the article).
4. **Social Hook**: (One "Mind-blowing" fact for LinkedIn).
