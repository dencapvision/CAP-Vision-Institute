# 🔄 WORKFLOW: TRANSFORM ARTICLE TO ACTION

Follow these steps to convert a knowledge insight into a transformative learning outcome.

## 1. 🔍 Content Analysis (Insight Curator)
Analyze the source article/content to extract metadata:
- **Core Theme**: (e.g., Dynamic Facilitation)
- **Target Persona**: (e.g., Senior HR, Team Lead)
- **Difficulty Level**: (Beginner/Expert)
- **Tags**: (Apply appropriate #tags for the Learning Intelligence System)

## 2. 🧠 Deep Reflection (Learning Coach)
Generate a **Reflection Panel** payload:
- **Insight Question**: Focus on the core lesson.
- **Mindset Shift**: A question to challenge the "Old Way vs New Way".
- **Immediate Action**: A low-friction task for tomorrow.

## 3. 🧩 Workshop Design (Facilitation Designer)
Create a **Workshop Agenda** (15-60 min):
- **Objective**: What will the team achieve?
- **Process**: (Icebreaker → Exploration → Co-creation → Reflection).
- **Tools**: Recommend specific CAP Vision cards or canvases.

## 4. 🚀 Action Planning (Knowledge-to-Action)
Generate an **Action Plan Template**:
- **7-Day Roadmap**: Daily micro-tasks.
- **KPI/Success Signal**: How to know it's working.

## 5. 📢 Content Multiplier (Repurposing Agent)
Create derivative assets:
- **Micro-learning**: 3 key bullet points.
- **Social Hook**: A magnetic LinkedIn post draft.
